# 战斗 HUD · 三版待选原型

2026-11-17。用户要求大幅精简顶部 HUD，并要求植物冷却始终可见。此交付只比较三版，不替用户选择或修改线上战斗 HUD。

身份：沿用当前后院游戏实际美术、草地、角色、植物；深叶绿 #294522、羊皮纸 #fff3ce、阳光金 #f4cb53、危险红 #dc5237；中文沿用现有 PingFang / STHeiti 字体。HUD 为操作界面，目标为即时识别生命与武器冷却，尽量让出战场。

共同删减：常驻波次、击杀、金币、钻石、小地图、Boss 倒计时、精英列表；这些信息移入暂停页。保留生命、经验/等级、始终可见的六种武器冷却、暂停入口。Boss 生命仅交战时出现。暂停可看统计、植物等级及 Lv.5 质变、地图；不能用关闭 HUD 的方式删除必要功能。

A 单行状态：顶部 44px 一行生命/计时/暂停，顶边 3px 经验；底部透明植物栏只保留图像和冷却。优势为一眼看懂，风险为上下两处视线切换。
B 跟随角色：顶部仅计时/等级和暂停；生命/经验在角色下方，六条植物冷却跟随实际武器。取消底部面板。优势为视线集中在角色，风险为高密战斗时局部信息拥挤。
C 底边集中：顶部普通战斗完全留空，生命/经验/等级/计时/暂停及植物冷却集中底边。Boss 血条并入底边。优势为顶部最大视野，风险为操作手可能遮挡底部。

每版同场景、同数据、同精灵、同尺寸比较；演示数据不代表真实游戏进度。使用真实渲染器绘制确定性战斗画面；仅在原型构建时移除其 minimap 层，不修改游戏源渲染器。提供普通 / 首领 / 低血量 / 暂停与植物详情。支持视口选择、单版全屏、拖动角色。原型不运行战斗模拟与伤害结算。

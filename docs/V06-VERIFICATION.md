# v0.6 分阶段验收

## 已完成

1. **离线机制检查**：49 项通过（45 项游戏机制 + 4 项 Sites 包装/路由检查）。覆盖所有主动植物实际造成伤害、抛射/黄油、连锁/激光、多向射击、地面与飞行判定、燃烧不锁死行走、敌人新技能、金币钻石、旧存档迁移、幂等结算、购买扣款、槽位限制、大地图移动与旋转不改世界坐标、双手触控向量。
2. **整局模拟**：81 局全部终局，80 胜 1 负；另有 3 局原地站立测试全部失败。包含三位主角、三张地图、三种旧版主武器和三个种子。后续地图带合理的永久生命/拾取升级。测试机器人会读取敌人预警并躲避，也会主动追首领，胜率不代表真实玩家。
3. **节奏**：机器人首次升级中位数 22.2 秒，60 秒等级中位数 4，120 秒为 7，进化约 141.2 秒，精英从首次受击到死亡中位数 29.5 秒。新增燃烧修正不影响该基础植物组合的模拟结果。
4. **手机布局**：12 组视口 × 11 场景 = 132 个通过状态。320×568、360×640、375×667、390×844、393×852、412×915、430×932、360×560、667×375、844×390，加竖屏/横屏安全区。检查营地、地图、准备、战斗、升级、暂停、构筑、结算、图鉴、植物商店、永久成长。未出现文档横向溢出、关键控件越界或损坏图片。
5. **真实浏览器交互**：用触摸事件分别从左、右侧拖动，验证移动、松手和取消停止；实际拾取精英掉落的 18 金币/1 钻石、立即存档、商店购买、重载保留、选择新解锁植物出战。测试只操作本地 QA 环境，测试结束恢复原本本地存档。
6. **渲染与音效**：真实 Canvas 截图检查接地、不同敌人、金币钻石、双排技能栏和两类攻击预警；音频解码完成、AudioContext running、战斗事件有活动声源。一次 88 帧浏览器样本的间隔中位数约 33.3ms、P95 34.3ms，仅代表该桌面浏览器测试环境。
7. **原版原声**：官方播放器实际播放 Grasswalk，观察播放计时从 00:01 推进到 00:02；关闭音乐面板再打开仍继续播放，关闭音乐可卸载播放器。
8. **资源加载**：限制网络速度时进度条显示中间进度；人为阻断一张僵尸图后显示重试，解除阻断并点击重新加载可完成进入。
9. **构建**：TypeScript、生产构建、28 个受保护文件校验、git diff --check 通过。

## 边界

这是浏览器视口与触控事件模拟，尚未在实体 iPhone/Android 上测试温度、电池、长时间帧率或音频中断。原版音乐使用作者官方联网播放器，需要用户点击播放；不是打包离线音轨，也不受游戏暂停按钮直接控制。存档属于当前浏览器和域名，清除站点数据会丢失进度。

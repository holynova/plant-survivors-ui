# v0.7 验收记录

- 设计：22 个基础颜色、间距/字号/圆角/触控/动效/图层 token；全部应用 CSS 颜色集中管理，文字对比度与预警几何合同测试通过。
- 特效：暖红危险边界与倒计时、胶囊形冲锋范围、钻地和施法标记；地面冲击、裂纹、冰冻和磁力痕迹在脚下绘制并限时消退；辣椒显示宽度与伤害判定统一。
- 优化：缓存接触阴影、平方距离碰撞、屏外裁剪、消除每帧事件数组反转，限制装饰性火苗/命中火花/浮动伤害数字。不降低敌人、弹道或伤害结算。
- 自动测试：48 项游戏/视觉合同测试、4 项静态发布测试通过；81 场种子战役全部终结，80 胜 / 1 负；3 场不移动测试均失败，排除无操作胜利。
- 多尺寸：12 配置 × 14 场景 = 168 张最终截图，0 项布局失败。另保留首轮失败记录和修复说明。PNG 原图在本地报告目录，便携 WebP 全分辨率截图随报告提交与发布。
- 修复发现：短屏首领横幅遮挡生命条；音乐面板侵入横屏底部安全区；浏览器失焦引发的进化测试夹具竞态。

## 性能结果与边界

真实生产模拟和 Canvas 渲染；固定种子、固定实体密度，390×844、DPR 2。每个测试刷新页面。测试隔离 React HUD 刷新与音频，不能等同全游戏真机跑分。

| 场景 | 怪 / 弹 / 敌弹 | 原速脚本 p95 | 4 倍 CPU 降速脚本 p95 |
| --- | --- | --- | --- |
| 常规 | 50 / 80 / 20 | 3.0 ms | 4.0 ms |
| 正常数量上限 | 160 / 240 / 80 | 5.1 ms | 10.4 ms |
| 超量 | 320 / 800 / 160 | 7.4 ms | 未完成稳定采样 |

有效测试各采样 180 帧。原速与上限降速实际 rAF 中位数约 17–18 ms，p95 约 35 ms；存在偶发隔帧，不能宣称锁定 60 FPS。超量+4倍降速在 18 秒内只有 22–28 帧，诊断期单帧脚本约 27–30 ms，且出现约 1 秒的 rAF 间隔。确认可见且有焦点后仍复现，因此明确标为未通过，保留逐帧数据，不把缺失数据算成零耗时，也不外推实体手机性能。正式上限场景通过当前脚本预算；真实手机 Safari/GPU/热降频仍需实体设备验收。

旧版同夹具原速上限 p95 5.4 ms、超量 9.1 ms；降速上限 14.3 ms。测试环境存在调度波动，因此报告展示原始数值而不作精确加速比例承诺。

报告：`docs/reports/mobile/index.html`。固定复测：`npm run test:mobile` / `npm run test:performance`；极限或采样失败使性能命令非零退出。报告由本次数据动态生成。

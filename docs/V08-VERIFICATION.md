# v0.8 性能与受击验收

实现源码：27e4687；对照源码：ddee8b5（v0.7.1）。最终发布提交还包含本报告、实际截图与数据。

- 55 项机制/视觉/碰撞/音频单测通过，4 项 Sites 包装检查通过；设计 token、28 个受保护 runtime 文件和 TypeScript/生产构建通过。
- 81 局种子战斗：80 胜、1 负，与旧版相同。6 个种子 × 180 帧逐帧深比较完整 Run 状态；跨网格击退、范围伤害、弹道穿透、随机掉落结果相同。
- 2 轮 × 3 场景 × 1×/4× CPU 的同负载比较。未降低压力实体数、特效数、伤害或模拟频率。12 次优化后采样全部取得180帧，预算通过。
- 极限 320 怪 / 800 弹 / 160 敌弹：1× 总脚本 p95 两轮中位数 9.45 → 2.95 ms（下降68.8%）；模拟5.55 →0.90ms，绘制3.55 →2.05ms。4× 基线两轮均未完成30帧预热，优化后均180帧，总脚本p95中位12.40ms。此组不计算提升百分比。
- 正式上限160怪/240弹/80敌弹：4×工作p95 11.95 →6.00ms（下降49.8%）。原速普通场景2.95 →2.65ms。原始各次数据、浏览器帧间隔与截图见 performance HTML，不只报告最优轮次。
- 基准隔离了React HUD及音频；帧间隔多在33–35ms，极限4×两轮p95为48.5/35.2ms。脚本耗时改善不等于实体手机60FPS，不掩盖宿主调度与GPU限制。
- 真正的僵尸近身攻击使生命125→115，HUD aria值115、填充比例0.92；实际截图显示伤害数字、受击帧与冲击线。音频running，hurtPlayed=1，捕获WebM经FFmpeg解码平均-22.6dB、峰值-9.0dB，非静音。
- 首次录音测试的固定停止时间早于低帧率宿主的受击截图，未记通过；改为观察实际受击状态后停止，再通过。WebM音量用离线解码验证，避免新AudioContext受自动播放策略影响。
- 多尺寸布局沿用12配置×14场景，战斗采用80/125生命，新增血条与文字边界检查。结果见 mobile/index.html 与 devices.json。

图形血条使用危险红、木框、纸白数字、阳光金掉血尾迹；低生命边框增强，减少动态关闭位移和屏幕闪光。普通声音保留11个声部额度，总14个，伤害/首领/胜负等高优先级可抢占普通声部；静音仍完全生效。hitAt 独立信号避免200条事件上限吞掉伤害提示。

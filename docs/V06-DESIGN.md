# v0.6 大花园远征

## 研究依据与改编范围

这次选取跨代、有明显玩法差异的代表植物，并非穷尽系列全部植物。当前是 **26 种植物 + 1 种装备、12 类普通敌人 + 2 类精英 + 1 个首领**。

- 一代：保留豌豆、寒冰、坚果、向日葵等，加入卷心菜、玉米黄油、西瓜、樱桃、辣椒、地雷、大嘴花、窝瓜、杨桃、仙人掌、火炬与磁力菇。投射物、触发范围、破盾规则和控制效果分别实现。
- 二代：[EA 官方介绍](https://www.ea.com/games/plants-vs-zombies/plants-vs-zombies-2/features?isLocalized=true)介绍激光豆、喷气敌人等；[PopCap 官方植物介绍 PDF](https://static-www.ec.popcap.com/misc/pvz2/PVZ2_Hype.pdf)说明菜问、火龙草和闪电芦苇。这里改编为近距挥拳、扇形灼烧、目标间连锁闪电；另有回旋镖、椰子炮和冰冻生菜。
- 三代：[PopCap CU6 更新](https://forums.ea.com/blog/plants-vs-zombies-game-info-hub-en/pvz3-state-of-the-lawn---content-update-6-cu6/13817931)介绍 Cabbage-volt 及竹子角色。这里把电能卷心菜实现为电荷抛射、落地后连锁，把竹笋实现为三枚窄角穿透弹。
- 上述机制为本项目的幸存者玩法改编，不是原作数值复刻。中文名称沿用常见译名，三代融合植物属于机制参考。

## 世界与移动端操作

参考 [Phaser 官方 Cameras 文档](https://docs.phaser.io/phaser/concepts/cameras)中的跟随镜头、世界边界和独立 UI 思路，以及[相机跟随瓦片地图示例](https://phaser.io/oss/examples/v4.1.0/camera/view/follow-zoom-tilemap)。本项目仍用现有 Canvas 运行时实现，没有为了相机更换引擎。

三个连续世界分别为 4800×4800、5400×4200、4200×5600 逻辑单位。镜头平滑跟随，远处有边界；不是无限生成的无边界地图。横竖屏只改变可视范围，不重缩放玩家、敌人、投射物、战利品或锁定攻击位置。渲染裁剪屏外实体，地面复用镜像拼接瓦片，屏外普通怪从远处重新进入；精英和首领不会因离开视野消失。小地图与方向箭头帮助追踪强敌。

触摸战场任意空白处建立临时移动原点，2px 死区、约 26px 达到全速；超长拖动会让原点跟随。左右手对称，松手/取消/失焦停止。第二根手指不会接管第一根手指，按钮与弹窗不触发移动。轮盘弱化且仅触摸时可见。仍支持 WASD / 方向键。

## 接地与预警

逐帧读取不透明脚底接触行，角色的地面坐标对齐该行；阴影中心直接在接触点，取消脚下彩色发光底盘。新怪使用四帧行走条带，攻击以倾身/施法表现，受击闪白、击退，死亡倒伏淡出。飞行怪有刻意的高度差和较淡地面影子。

重击预警的半径等于伤害半径（首领 72、精英 50），带内圈、刻度、外缘倒计时和收缩环。冲锋通道宽 70、长约 202，与 280×0.72 的冲刺一致；目标方向锁定后不会偷改。矿工落点与远程蓄力另有提示。

## 战利品与成长

精英保证 18 金币与 1 钻石；首领保证 60 金币与 4 钻石。普通怪有小概率掉金币，阳光仅提供本局经验。拾取后立即入库；失败、撤退仍保留已经拾取的货币，胜利会收回场上剩余货币。

旧种子余额迁为金币，旧地图解锁和纪录保留。按 runId 与累计拾取量去重，购买原子扣款，结算不重复加钱。新植物进入升级候选池，并可作为主动初始植物；每局上限 6 主动 + 3 被动。厚实围裙增加永久生命、拾取手套增大拾取范围、幸运钱袋提高金币价值。浏览器本地存档，无账号云同步。

## 资源与声音

首次进入加载本地角色、图标、场景和音效，按已完成资源数显示真实进度。6 路图片队列，失败可重试；音效失败允许静音继续。缓存由浏览器管理，不承诺清理缓存后仍离线可用。新增攻击、金币和钻石使用独立合成音色。

原版音乐接入 [Laura Shigihara 官方 Bandcamp 原声](https://laurashigihara.bandcamp.com/album/plants-vs-zombies-soundtrack)的公开嵌入播放器，可选 Grasswalk、Moongrains、Graze the Roof、Brainiac Maniac。必须联网并在播放器点播放；回到游戏继续播放，暂停与曲目切换由官方播放器控制。没有下载、重打包或声称拥有原版录音；原有离线合成音乐单独标明。

新增图片使用内置 image_gen 生成后切分、归一化。见 [原始提示词](V06-ART-PROMPTS.md)、[来源清单](v06-art-sources.json)；原始图存于 `assets/source-v06/`，实际使用文件位于 `public/assets/game/`。

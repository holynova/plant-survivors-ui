## 性能结论

图片下载体积减少 89.2%，暂停画布重绘归零。新机制与美术会增加部分场景 CPU 绘制成本，不把本版描述为所有指标都更快。

两版使用相同 390×844 视口、DPR 2、780×1382 画布、实体数量与压力夹具，每组两轮。正式上限 160 怪 / 240 友弹 / 80 敌弹，4 倍 CPU 降速下 v0.9 工作耗时 p95 两轮中位数约 7.1 ms，v0.8 约 6.75 ms。它是模拟+绘制工作耗时，不是整机帧时间或真机 FPS。

超量 320 / 800 / 160 场景在 4 倍降速下未完成目标 180 帧采样，新版两轮仅 81 和 64 帧，存在长帧。全部原始数据保留，不把“超过最低 60 帧可分析”记作“压力流畅通过”。未减少实体或伤害来制造改善。

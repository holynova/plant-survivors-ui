# v0.10 无限生存改版

全部 15 项需求及逐项证据见 `docs/reports/v10/index.html`。

- 不再因计时结束失败或击败首领自动结束，直到生命归零或主动撤退。击败首领后死亡结算仍解锁下一地图。
- 四种首领轮换与精英持续增援；敌人速度、移动策略、蓄力、连射、召唤和潜地进一步区分。
- 新生成空车戴夫 16 帧、三类首领、命中特效、弹药、金币/钻石/草莓、地图装饰及两种地表；修复小鬼和气球非等高切图。
- 主动植物围绕角色排列，远程枪口与植物坐标共享；Lv.5 的具体质变在准备/升级/装备界面展示。
- 准备页显示灰色锁定植物，可查看价格并购买；整合首领与精英进度条，移除提示 toast 和多余圆圈。
- 普通怪 5.5% 回复掉落；精英与首领保证回复果实，满血不浪费。

验证：79 项机制测试、81 组 10 分钟模拟、12 尺寸 180 场景，旧版/新版各 12 次固定密度性能采样。报告明确区分 JS 耗时、呈现帧间隔与实体手机性能。首轮布局失败和修复后截图均保留。

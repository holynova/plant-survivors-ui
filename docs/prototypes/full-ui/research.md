六套方案使用原创人物、造型、图标和页面布局。游戏参考图用于观察界面结构和材料。竖屏 390×844 是评审目标尺寸，生成总板内每格比例近似。玩家手指可在空白战场区拖动。普通战斗上方保留生命、等级、已生存时间和暂停，顶边显示经验。底部始终显示主动植物冷却，首领出现时才加一行血条。当前战斗无倒计时。详细信息、地图、设置收进暂停层。

## 完整动线

**载入 → 营地 → 地图 → 主角 → 配装 → 生存 → 首领 → 结算 → 再来或营地**。锁定植物从配装打开解锁确认；关掉确认回到原配装状态。还可从战斗进入升级、Lv.5 质变确认、暂停、设置和本局花园。营地图鉴能打开单个条目，成长含种子商店及永久成长。

每套 18 个主要分镜。实施时还要覆盖低血量、精英、暂停的植物与地图页、退出确认、能力耗尽、金币或钻石不足、已满级、掉线或资源重试、通关后地图解锁、首次引导和本局恢复。锁定与不足状态应写明条件。结算明确死亡或主动撤退。图中的示例数值只用于视觉排版。

## 界面交付约束

正文目标 14–16px，操作区至少 44×44 CSS px，4/8px 为基础间距。底部保留系统手势区，适配刘海和横竖屏翻转。确认重要状态的颜色含义一致：经验用金色，冷却用绿色，受伤和警告用红色。图上的装饰色与示例未定稿，实施以这些规则为准。需要在按下、冷却、禁用、可解锁四种状态检查可辨识度。

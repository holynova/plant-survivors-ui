# HUD 三版交互原型

打开本目录 `index.html`，所有脚本和91项现有游戏美术均内嵌，无需启动服务、联网或安装依赖。使用实际项目渲染器生成战场，不是 AI 生成界面图。演示数据固定，HUD 的交互可以操作；不运行伤害/升级模拟、不保存进度。

- A 单行状态：顶边经验 + 顶部生命/计时/暂停；底部6株植物与冷却。
- B 跟随角色：生命/经验跟随角色群；6条冷却跟随对应的环绕植物；没有底部栏。
- C 底边集中：普通战斗顶部完全空出，所有常驻状态与植物冷却收进底部。

普通 / Boss / 低血量 / 暂停可直接切换，支持5种视口选项、单版打开、拖动角色、播放与冻结动态、暂停页植物/地图标签。植物说明包含真实 Lv.5 质变效果。

截图：`comparison.png` 是普通战斗三版对照，`comparison-boss.png` 是 Boss 对照；`a-*`、`b-*`、`c-*` 为390×844单版截图。

验证：4种视口×3版×4状态=48项初始边界与图片检查通过（checks-first.json）；修复 B 顶边拖动导致的 Boss 血条遮挡后，320×568、390×844、844×390 的6条冷却均可见、与 Boss 条不重叠（interaction-checks.json）；实际按钮验证暂停、植物详情、地图、继续、Escape、动画开关及 file:// 离线打开。补查小屏/横屏植物说明可滚动。独立复核指出的2项问题均已解决。

这些是 Chromium 视口模拟，不代表实体手机拇指遮挡或高密度长时间战斗的最终验收。B的随身冷却在实战密度下仍需可读性验证；C的底栏需手机拇指测试。方案尚未选定，线上游戏未修改。

源码：`design/hud-prototypes/`；重建：在项目目录执行 `node scripts/build-hud-prototypes.mjs`。构建时只在原型私有 bundle 中移除旧 minimap 渲染层，生产游戏源文件不变。主题颜色来自 `src/design/tokens.json`，美术来源沿用 `docs/v10-art-sources.json`。

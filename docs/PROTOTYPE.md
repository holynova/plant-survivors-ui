# 植物幸存者 · 经典后院

按用户选定的第一套九屏设计板制作的移动端交互 UI 原型。视觉基准：`/Users/sym/code/plant-survivors-design/concepts/01-classic-garden.png`；完整玩法提案在相邻 `plant-survivors-design/DESIGN.md`。

## 预览

当前开发预览：<http://localhost:5194/>。桌面左侧可以逐屏检查；窄屏下审阅导航移至画面外底部。右上角可在 iPhone / Pixel 10 模板之间切换。

包含营地、选关、出战准备、战斗、升级、进化、构筑、首领战、结算九个场景，以及图鉴、成长说明和暂停面板。

主流程：开始远征 → 前往后院 → 选初始植物 → 出发 → 拾取阳光升级 → 重掷/选择 → 查看进化效果 → 继续战斗 → 首领来袭 → 通关 → 返回营地。

摇杆支持拖动与松手停止，也可聚焦摇杆后使用方向键。植物栏打开构筑；配方可追踪。升级重掷有次数限制；结算种子演示只领取一次。不同初始植物的首槽、升级主选项和进化名称会随选择改变。

## 边界

这是可点击UI原型。敌潮、战斗计时、伤害和结算为示例；尚未实现完整战斗、碰撞、经验曲线、长期存档、真实音频或联网。暂停面板中的音乐开关仅演示设置状态。

不以这版截图或交互检查宣称战斗平衡已经完成。图中原有向日葵/坚果槽位与示例伤害分布优先按选定图呈现；正式战斗接入时按玩法设计统一被动归属。

原设计板各手机面板只有约316×450—486像素，并非真正390×844视口。实现使用393×852手机运行时，安全区域内393×770；保留内容顺序、主次、配色、材质和插画题材，重排至实际手机比例。部分插画从参考图提取，另一些依据原图生成独立透明素材。不是像素级同一图片。
